## 🪟🐧🍎 COMANDOS (para todos los sistemas)

```bash
# Para iniciar (elige el que funcione en tu sistema):
python start.py
python3 start.py

# Para analizar un archivo específico:
python start.py foto.jpg
python start.py cancion.mp3
python start.py video.mp4
python start.py documento.pdf

# Para guardar resultados en JSON:
python start.py imagen.jpg --json
```

## 🔧 PROBLEMAS COMUNES

### ❌ "Python no está instalado"
```
Descarga desde: https://www.python.org/downloads/
```

### ❌ "externally-managed-environment" en Linux
```
# start.py ya lo soluciona automáticamente
# Si quieres manual:
pip install --break-system-packages -r requirements.txt
```

### ❌ "ffmpeg not found" (para videos)
```
# Ubuntu/Debian
sudo apt install ffmpeg

# Arch/Manjaro
sudo pacman -S ffmpeg

# macOS
brew install ffmpeg
```
